## 主模式

| 按键 | 作用 |
| --- | --- |
| 输入 | 实时搜索(防抖) |
| `↑` `↓` / `Ctrl+P` `Ctrl+N`(`Alt+P` `Alt+N`) | 选择结果 |
| `Tab` | 切换 文件/内容 模式 |
| `Ctrl+F` / `Alt+F` | 匹配切换:文件=精确/模糊;内容=字面量(-F)/正则 |
| `Ctrl+T` / `Alt+T` | 可视化筛选栏(时间 / 条数 / Git) |
| `Ctrl+R` / `Alt+R` | `--snapshot` 检索会话:返回选择器重新选容器/Pod |
| `Ctrl+E` / `Alt+E` | 编辑器打开选中文件到对应行(需配置 `[editor]`) |
| `:` | 命令面板(输入为空时;全部功能的无冲突入口) |
| `Ctrl+G` / `Alt+G` | 搜索历史(`Enter` 回填 · `Del` 删除) |
| `\|` | 结果喂给外部命令(输入为空时;占位符 `{path}` `{line}` `{text}`) |
| `Ctrl+B` / `Alt+B` | 状态栏 blame 摘要开关 |
| `R` | AST 批量替换(输入为空时;需 ast-grep 与干净 git 工作区) |
| `Ctrl+O` / `Alt+O` | less 翻页器打开当前预览(`q` 返回) |
| `Ctrl+Y` / `Alt+Y` | 复制选中行(日志)/绝对路径(文件)到剪贴板 |
| `Ctrl+Space` / `Alt+M` | 标记/取消当前行(多选,`Enter` 输出全部标记项) |
| `PgUp` `PgDown` | 滚动预览(图片预览除外) |
| `Enter` | 选定(stdout 输出)并退出 |
| `Esc` | 清空搜索词 → 清空标记 → 退出(递进) |
| `Ctrl+C` | 任何时刻退出 |
| `?` / `F1` | 键位帮助(`?` 需输入为空;F1 任何时候) |

## 容器/Pod 选择器内

| 按键 | 作用 |
| --- | --- |
| 输入 | 模糊过滤(名称+镜像/namespace) |
| `↑` `↓` | 选择目标 |
| `Tab` | 标记/取消标记目标(实时模式多选,最多 4 个) |
| `Ctrl+R` / `Alt+R` | 刷新列表 |
| `Enter` | 有标记用标记集、无标记用光标项,进实时分屏(`--snapshot` 则为单目标快照检索) |
| `Esc` | 退出 |

## 实时日志视图内

| 按键 | 作用 |
| --- | --- |
| `j` `k` `↑` `↓` | 滚动焦点面板(上翻即暂停**该面板**跟随,其余面板不受影响) |
| `Ctrl+D` / `Ctrl+U` | 焦点面板半页滚动 |
| `PgUp` `PgDown` | 焦点面板整页滚动 |
| `G` / `End` | 焦点面板回底并恢复跟随 |
| `g` / `Home` | 焦点面板到顶 |
| `Tab` / `Shift+Tab` | 循环切换焦点面板 |
| `1` - `4` | 直达焦点面板 |
| `y` | 复制焦点面板的 `scx-rg --follow <落盘文件>` 到剪贴板(OSC 52) |
| `?` / `F1` | 键位帮助(实时视图无文本输入,`?` 恒为帮助键) |
| `Ctrl+R` / `Alt+R` | 返回选择器重选容器/Pod(停掉全部实时进程) |
| `Ctrl+C` / `Esc` | 退出 |

## 筛选栏内

| 按键 | 作用 |
| --- | --- |
| `←` `→` | 在预设间移动,**即时生效** |
| `↑` `↓` / `Tab` | 在 时间/条数/Git 段间切换 |
| `Enter` / `Esc` / `Ctrl+T` | 收起(筛选保留) |

## 堡垒机 / 浏览器 Web 终端

浏览器和堡垒机常在按键到达 SSH 会话前截获 Ctrl 组合键(`Ctrl+T` 新标签页、`Ctrl+F` 页内查找……)。三层应对:

1. **Alt 别名(内置)**:上表所有 Ctrl 功能键都有 `Alt+字母` 等价键,Alt 组合键基本都会透传
2. **命令面板(内置)**:输入为空按 `:`,复制、翻页器、编辑器、筛选栏等**全部功能**都能从面板执行,只用普通字符键
3. **环境侧(可选)**:浏览器装 Shortkeys 类扩展屏蔽对应快捷键;堡垒机页面装成 PWA 应用窗口;或改用原生 SSH 客户端

:::note[macOS Option 键]
本地终端若按 `Alt+T` 出现变音符 `t`,需在终端设置里把 Option 键行为改为 *Meta/Esc*(iTerm2 选 `Esc+`)。
:::

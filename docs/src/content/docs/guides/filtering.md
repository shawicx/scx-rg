---
title: 结果筛选(Ctrl+T)
description: 时间窗、条数封顶、实时滑窗与 Git 文件筛选,即时生效。
---

按 `Ctrl+T`(或 `Alt+T`)打开可视化筛选栏,三段预设 chips,`←` `→` 移动光标**即时生效**,`↑` `↓`/`Tab` 切段,`Enter`/`Esc` 收起:

```text
时间   实时  全部  1分钟  5分钟  15分钟  1小时  6小时  24小时
条数   全部  20条  50条  100条  500条  5000条
Git    全部  仅改动  仅暂存    ← git 仓库内才出现
```

全部在客户端完成,**不重新抓取日志**。生效的筛选显示在底部状态栏(如 `实时 / 末50条`)。

## 时间筛选

- 只显示行首时间戳在「过去 X 分钟/小时」内的行;自动识别 docker/kubectl 快照(RFC3339)、`2026-08-20 10:00:00`、nginx、syslog 等常见格式
- 无时间戳的行(多行堆栈的续行)保留;整轮结果都检测不到时间戳时该段失效并提示
- **实时** = 最近 30 秒的滑动窗口:配合 `--follow` 就是实时日志窗——即使没有新日志写入,超窗的旧行也随时间自动滚出列表(窗口每秒滑动一次)。**切到实时时,条数若还停在「全部」会自动收窄为 50 条**(你在条数段手动选过档位则不覆盖)

## 条数封顶

只保留最新的 N 条命中(配合搜索词就是「最近 100 条 ERROR」)。跟随模式下每轮刷新自动重新过滤。

## Git 筛选

git 仓库内筛选栏多出第三段:

- **仅改动**:只看相对 HEAD 有变更(tracked)的文件
- **仅暂存**:只看已 staged 的文件
- 文件模式在枚举层过滤,内容模式按路径过滤;未跟踪的新文件不在 `git diff` 语义内

多目录 workspace 下 Git 段隐藏(文件集口径是主根相对路径)。

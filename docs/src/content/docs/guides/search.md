## 双模式

`Tab` 随时切换,状态栏徽标显示当前模式:

| 模式 | 行为 | 依赖 |
| --- | --- | --- |
| 文件 | fzf 式模糊匹配文件名(空格分词 AND、边界/连续加权评分,命中字符高亮);完整子串命中大幅优先 | 无 |
| 内容 | `rg --json` 流式全文搜索,结果边搜边出;搜 `log.error(` 这类含元字符文本自动按字面量兜底,不报错 | [ripgrep](https://github.com/BurntSushi/ripgrep) |

文件名搜不到时自动回退全文搜索(状态栏显示「全文」徽标),不用手动切模式。

## 匹配行为切换

`Ctrl+F`(堡垒机用 `Alt+F`):

- **文件模式**:精确匹配(分词必须是完整子串)⇄ 模糊匹配
- **内容模式**:字面量 `-F` ⇄ 正则(粘性,状态栏「字面」徽标)

## 实时与防闪烁

输入即搜,默认 200ms 防抖(可配置)。搜索进行中**旧结果保持可见**(状态栏显示 `* 搜索中`),新结果到达才整体替换——连续输入、日志跟随刷新都不会整屏闪烁。

## 多选输出

1. `Ctrl+Space`(或 `Alt+M`)标记/取消当前行,自动下移;列表行前缀显示 `✓`
2. `Enter` 一次输出全部标记项(按列表顺序,已被过滤的跳过)

输出走 stdout,天然支持 `$(...)` 命令替换。`Esc` 递进退出:先清输入 → 再清标记 → 最后退出。

## 搜索历史

`Ctrl+G`(或 `Alt+G`)打开最近 100 条查询(最新在前):`↑↓` 选择、`Enter` 回填执行、`Del` 删除。

只有「实际使用过」的查询才进历史(Enter 选定 / 编辑器打开 / 管道执行),输入中间态不记录。落盘 `~/.local/state/scx-rg/history`,退出时写入。

## 多目录 workspace

命令面板(`:` 输入为空时打开)→「添加搜索目录」:最多追加 8 个额外搜索根(支持 `~` 展开)。主目录结果保持相对路径,额外目录显示绝对路径,状态栏显示 `+N 目录`。「清除额外搜索目录」一键还原。
